# 🎗️ Projeto Lange — Website Institucional

 Website estático e responsivo desenvolvido como projeto acadêmico colaborativo para o **Projeto Lange**, uma organização sem fins lucrativos dedicada ao apoio de pacientes oncológicos. O objetivo principal é expandir o alcance da ONG, facilitando o voluntariado e a arrecadação de doações.

🔗 **Acesse o site:** [Clique aqui para acessar o Projeto Lange](https://alef-developer.github.io/projeto-lanje/)

---

## 🚀 Funcionalidades Principais

* **Navegação Multipáginas:** Estrutura clara dividida em *Início*, *Como Ajudar* e *Ações*.
* **Cópia Rápida de Chave Pix:** Botão interativo em JavaScript que copia a chave Pix para a área de transferência com notificação visual (*toast*).
* **Design 100% Responsivo:** Adaptado para dispositivos móveis, tablets e computadores, com menu *hambúrguer* interativo.
* **Canais de Contato Direto:** Links integrados para atendimento via WhatsApp e redes sociais (Instagram).
* **Mural de Transparência:** Espaço dedicado às campanhas ativas, histórias de pacientes e parceiros locais.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização, layout flexível (Flexbox/Grid), media queries para responsividade e variáveis.
* **JavaScript (ES6+):** Manipulação do DOM, interatividade do menu mobile e funcionalidade de cópia da chave Pix.
* **Inteligência Artificial:** Utilizada como ferramenta de apoio durante o desenvolvimento do código e organização do projeto.
